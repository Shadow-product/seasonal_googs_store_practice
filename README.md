# 🌤 Seasonal Goods Store

## Описание:

Seasonal Goods Store - это прототип интернет магазина с использованием Open Meteo API (API погоды).
Прототип интернет магазина Seasonal Goods Store написан используя ООП подход (Объектно Ориентированное Программирование JavaScript).
Интернет магазина представляет собой веб-сайт для просмотра погоды на основе интернет магазина товаров.
Пользователь может выбирать товар, добавить в корзину, перейти в каталог, в корзину, удалить товар, оформить заказ (заглушка) и войти / зарегистрироваться на веб-сайте. 
Интерфейс адаптивный: на мобильных устройствах работает бургер-меню. На десктопах бургер меню скрыт и на планшетах.

- Войти / Зарегистрироваться на сайте

---

## Возможности:
- Выбор товара по кнопке подробнее или на карточку товара на главной странице.
- Добавление в корзину товар, перейти в каталог и в корзину на странице товары.
- Удалить товар из корзины.
- Оформить заказ (заглушка) на странице корзина.
- Войти / Зарегистрироваться на странице вход / регистрация. И глазок для просмотра пароля.
- Адаптивный интерфейс (бургер-меню на телефонах).
- Сохранения состояния карточки гостя, выбор пользователя товара, общий список пользователей,
текущий пользователь и карточки погоды загрузка из кэша после получения данных из API.

---

## Технологии
- HTML5 - структура страниц.
- CSS3 - адаптивный дизайн.
- JavaScript (ES6+) - логика приложения, работа с DOM-элементами и сохранение данных.
- localStorage - хранения данных пользователей, выбранный товар.
- Open Meteo API (для получения погодных данных)
- Git - система контроля версии для современной разработки проекта.
- GitHub Pages - для публикации готового проекта.
